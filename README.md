# Fashion & Beauty Store

A modern and responsive e-commerce website for Fashion and Beauty products built with React.

##  Project Overview

This is a full-featured online store where users can browse fashion and beauty products, view details, add items to cart, and place orders. Built as a collaborative project.

##  Features

- Responsive design (Mobile + Desktop)
- Product listing page
- Product detail page
- Shopping cart
- Clean and modern UI
- Fast performance with React

##  Technologies Used

- React.js
- HTML5
- CSS3
- JavaScript (ES6+)
- firebase
- (More libraries will be added - React Router, etc.)
